# Flappy Bird 2026.2
Projeto desenvolvido por Samuel Santos Figueirêdo para a Universidade Estadual da Bahia (UNEB)

## Descrição:
Gameplay do jogo Flappy Bird para atividade da matéria Programação para Jogos 2026.2

## Objetivo:
Nesse jogo, você controla Felpudo em um avião, buscando destruir as criaturas que estejam indo em sua direção. Ao destruir uma certa quantidade, Uruca enfurecido por você estar destruindo os minions dele, vai buscar lhe derrotar!

## Comandos de movimentação:
-	Andar verticalmente:		W/S (Cima/Baixo)
-	Andar horizontalmente:		A/D (Esquerda/Direita)
[Há uma força empurrando o jogador à esquerda sempre, como se fosse o vento]
-	Projétil Simples:		Clique do botão esquerdo do mouse (Cooldown de 0.5 segundos)
-	Projétil Poderoso:		Clique do botão direito do mouse (Cooldown de 10 segundos)
-	Reiniciar:		R (Funciona somente com Game Over ou Vitória)
